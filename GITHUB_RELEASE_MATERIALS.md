# GitHub 发布文案

这份文案用于把 `Price Gap Map` 以更像正式开源项目的方式发布到 GitHub。内容尽量保持“方向清楚、边界明确、不过度承诺”。

## 仓库名建议

首选：

- `price-gap-map`

备选：

- `price-intelligence-prototype`
- `evidence-based-procurement`

更推荐 `price-gap-map`，因为它更短、更像一个项目名，也能保留“价差不是只有价格数字，而是信息结构”的产品判断。

## About 描述

### 推荐版

```text
An evidence-first prototype for procurement decisions that explains price gaps through constraints, evidence quality, and fulfillment risk.
```

### 更简短版

```text
An evidence-first prototype that explains price gaps beyond the listed price.
```

### 中文说明版

```text
一个面向真实采购决策的价差解释型原型项目，强调证据、限制条件与履约风险。
```

说明：

- GitHub 仓库的 `About` 建议优先用英文。
- 推荐版更适合正式开源项目主页。
- 简短版更适合字符空间更紧的场景。

## Website / Homepage

如果你暂时没有独立站或 GitHub Pages，建议先留空。  
如果后面要挂演示页，优先考虑：

- 交互式 PRD
- LLM 价格样本页
- 项目主页型 landing page


说明：

- GitHub topics 建议全部用英文、小写、短横线连接。
- 不建议现在就打上过重的词，比如 `best-price`、`automation`、`shopping-bot`，容易让仓库能力显得过度承诺。

## 首次 commit message

### 推荐版

```text
feat: initialize Price Gap Map prototype repository
```

可配套 body：

```text
- add product concept draft and interactive PRD
- add public LLM pricing sample and retail sample modules
- add Singles' Day beauty procurement report template
- document project scope, boundaries, roadmap, and contribution guide
```

### 更像开源首发版

```text
chore: bootstrap Price Gap Map open-source prototype
```

可配套 body：

```text
- set up examples, modules, and templates structure
- add bilingual README and repository metadata
- add disclaimer, roadmap, and contributing guide
- prepare the repository for public iteration on GitHub
```

### 如果你想更偏产品感

```text
feat: launch the first public prototype of Price Gap Map
```

可配套 body：

```text
- introduce the evidence-first price gap framing
- include runnable data samples and reporting templates
- define current scope and non-goals
- make the repository ready for open discussion and iteration
```
