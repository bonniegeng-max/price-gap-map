# beauty-11-report-template

这是一个面向双十一化妆品采购场景的中文自包含 HTML 报告模板，适合直接替换为真实商品数据后用于：

- 采购评审会
- 大促选品比价
- 渠道风险复核
- 签报或归档前的证据整理

模板文件：

- `index.html`：最终报告模板，已内嵌全部样式，无需任何外部依赖

## 如何替换成真实商品

建议按下面顺序替换，避免只改价格、不改规则口径而导致报告失真。

### 1. 先改商品标准口径

在“示例商品信息”区域，替换以下内容：

- 品牌 / 系列
- 规格与容量
- 国行 / 海外版 / 礼盒版等版本说明
- 采购用途
- 目标价
- 批次与剩余保质期要求

建议统一为一个标准比较单位，例如：

- 单件 30ml
- 单件 50ml
- 单套礼盒
- 每 1ml 折算价

如果不同渠道不是完全同款，不要直接比较，先在“版本 / 规格 / 临期检查”区域写明差异。

### 2. 替换结论卡

将首页“结论卡”替换为真实结论，建议只保留这 3 类表述之一：

- 建议采购
- 有条件采购
- 不建议采购

同时改掉以下信息：

- 建议采购量
- 下单时间窗口
- 失效条件
- 触发复核的阈值

推荐写法：

```text
建议采购，但仅限官方旗舰店现货口径；若结算页赠品减少或发货期延长，则本结论失效。
```

### 3. 逐项替换真实到手价计算表

在“真实到手价计算框架”区域，替换为你的真实活动数据。建议保留这些行：

- 页面标价
- 店铺券
- 平台券 / 跨店满减
- 支付立减 / 会员折扣
- 赠品折算净值
- 运费 / 税费 / 保价 / 调拨成本
- 会员费分摊

通用公式：

```text
真实到手价 = 页面标价
          − 各类优惠
          − 赠品折算净值
          + 运费 / 税费 / 必要附加成本
          + 会员费分摊
```

注意：

- 满减和凑单必须写清楚摊销方法
- 只看商品页不够，尽量以结算页为准
- 如果有预售定金和尾款，建议拆成两套计算

### 4. 重算赠品折算

不要直接照搬活动页“赠品价值”。建议按下面逻辑重算：

```text
赠品净值 = 参考市场价 × 可转化系数 × 需求匹配系数 × 履约确定系数
```

替换时重点检查：

- 赠品是否随机
- 赠品是否限量
- 赠品是否只有支付后才能确认
- 赠品是否真的对你的采购用途有价值

如果价值不稳定，宁可少算，不要高算。

### 5. 替换渠道可信度评分

把模板中的示例分数改成你的真实判断。建议至少考虑：

- 是否官方旗舰店 / 平台自营 / 授权店
- 规则是否完整透明
- 版本、批次、有效期能否确认
- 售后、发票、退货是否清晰
- 是否有足够证据交叉验证

推荐阈值：

- `80+`：可采购
- `65–79`：有条件采购
- `<65`：仅保留线索，不建议直接下单

### 6. 完整填写“版本 / 规格 / 临期检查”

这部分不要删，真实使用时非常关键。建议至少填这 5 项：

- 版本一致性
- 规格与套组结构
- 批次与有效期
- 包装与条码
- 临期与清仓信号

如果有任何一项不能确认，建议在结论卡里同步写成“条件采购”或“不建议采购”。

### 7. 把每个关键判断挂到证据编号

在“证据表”中替换为真实凭证。推荐编号方式：

- `E01` 商品页截图
- `E02` 结算页截图
- `E03` 客服聊天记录
- `E04` 资质或授权证明
- `E05` 赠品清单
- `E06` 历史价格记录
- `E07` 对照渠道页面
- `E08` 签收验货照片

建议让报告里的关键结论都能对应到一个证据编号，例如：

- 页面标价来自 `E01`
- 优惠叠加来自 `E02`
- 批次承诺来自 `E03`

### 8. 按真实活动时间改时间线

将“关键时间线”替换成你的真实节点，例如：

- 预热期建档
- 开卖前核券
- 支付前复核
- 发货跟踪
- 签收验货
- 售后结案

如果是直播专场、预售尾款或跨境渠道，建议增加专门节点。

## 推荐使用方式

### 方式一：直接编辑 HTML

适合懂一点网页结构的同事，直接打开 `index.html` 修改文案和数字即可。

### 方式二：先列真实数据，再统一替换

建议先准备一份表格或文档，列出：

- 商品名称
- 各渠道页面价
- 可用优惠
- 赠品列表
- 有效期 / 批次信息
- 风险点
- 证据文件名

整理完后，再统一替换 HTML 内容，错误率更低。

## 替换时最容易漏掉的点

- 只改了页面标价，没有改赠品净值
- 只改了商品名，没有改版本 / 规格说明
- 只看直播口播，没有校验结算页
- 把宣传页赠品价值直接记进报告
- 没有填写证据编号，导致结论无法回溯
- 没有写临期阈值和售后风险

## 交付建议

如果你要把这个模板用于正式归档，建议同时保存：

- 最终 HTML
- 打印导出的 PDF
- 证据截图文件夹
- 原始价格明细表

这样后续复盘时可以直接回看，不需要重新找证据。
